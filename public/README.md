# Application de Messagerie Fullstack avec Docker

Exercice d'application web permettant d'enregistrer et de supprimer des messages dans une base de données PostgreSQL, entièrement containerisée avec Docker.

## 🛠️ Technologies
- **Frontend** : HTML5, JavaScript (Fetch API)
- **Backend** : Node.js, Express
- **Base de données** : PostgreSQL 18
- **Orchestration** : Docker Compose
